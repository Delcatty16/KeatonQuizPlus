
# CHANGELOG

  

## Version 1.0.0

  

* Initial release

+ Added the ability to change how many questions must be answered before the Keaton prize is rewarded.

+ Added the ability to change the amount of time it takes for Keaton to appear after cutting the grass.

+ Added 30 new questions to the quiz.

+ Added the ability to swap between the vanilla set of questions and the new set of questions.

  

## Version 1.1.0

  

+ Added An additional set of questions based on Ocarina of Time

+ Added the ability to change the color of the highlighted words during the quiz

+ Added an option to toggle whether or not the moon crashes upon answering incorrectly

+ The song that plays during the quiz will change if the question set is set to OoT

  

## Version 1.2.0

  

+ Added an additional set of questions using icons of NPCs, masks and items.

+ Added a check to change Keaton's intro text for when specifically speaking to it in a location Keaton isn't normally available in. (Should not affect normal play, but is there for future proofing)

  

## Version 1.3.0

  

+ Added an option to allow Keaton to check if the Keaton Mask is in the inventory and not just currently equipped.
	+ This allows for other forms of Link to take part in the quiz with unique dialogue for each.

+ Updated the "Moon Crash On Fail" option to choose between causing an instant death or Moon Crash upon getting a question wrong.
	+ Added unique dialogue for each option.
+ Replaced four questions in the OoT set to avoid duplicate questions between sets.
