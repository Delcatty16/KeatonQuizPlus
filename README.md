# Keaton Quiz Plus

Makes changes to the Keaton Quiz.

You can choose how fast Keaton will appear.

How many questions are required to receive the prize.

Choose between the vanilla set of questions or alternative sets of questions based on Majora's Mask(MM), Ocarina of Time(OoT) and Pictures.

Option to allow Keaton to appear by simply owning the Keaton Mask and not require it to be equipped. This also allows other forms to take part in the quiz.

Option to change the color of the highlighted words during the quiz.

Option to choose whether or not to have instant death or causing a Moon Crash upon getting a question wrong.
