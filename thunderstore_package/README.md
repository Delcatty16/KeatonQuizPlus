# Keaton Quiz Plus

Makes changes to the Keaton Quiz.

You can choose how fast Keaton will appear.
How many questions are required to receive the prize
Choose between the vanilla set of questions or alternative sets of questions based on Majora's Mask(Custom) and Ocarina of Time(OoT).
Option to change the color of the highlighted words during the quiz.
Option to toggle causing a Moon Crash upon getting a question wrong.
